# 모션 광고 하우스 스타일 (매주 제작용)

세준 사업들(LUFT·QURATOR·Perpline 등)의 홍보영상을 만드는 직원이 따르는 기준이다. 품질 기준은 세준이 준 레퍼런스(아마존풍 코드 모션그래픽 릴스) **이상**이다. 기준 작품은 `ads/video/luft-seoul` v2(2026-11-02). v1(회의 8.67점)은 대표 검토에서 "낙관이 너무 크고 촌스럽다, 마감이 낮다"로 반려됐다. 자체 채점이 후했다는 뜻이므로, 아래 10장 '반려에서 배운 것'을 먼저 읽는다.

## 1. 원칙
- 영상 생성 모델 0%. 전부 코드로 그린 모션그래픽(HTML + GSAP + canvas)을 HyperFrames로 렌더한다.
- 진짜만 보여 준다. 로고·심볼·상품 이미지·UI 라벨·옵션명은 각 저장소의 원본 파일과 `catalog`에서 가져온다. 다시 그리거나 지어내지 않는다.
- 금지:
  - 판매가 숫자, 수익 보장·투자 권유 문구(Perpline)
  - 실존 브랜드 로고, 애플 로고, 실존 인물 얼굴
  - LUFT 방향제 광고어(탈취·항균·천연·무해·무독성·안심·에코·히노키)
  - 외부 음원(사운드는 직접 합성), 유료 결제, 외부 게시·업로드
- 혜택은 사실만 쓴다. 예: "이름 낙관 무료", "전 상품 무료배송", "국내 제작 2–4 영업일".

## 2. 도구와 실행 (이 환경에서 확인됨)
- CLI 고정 버전: `npx hyperframes@0.8.230`. 실행 전 환경변수는 `HYPERFRAMES_NO_TELEMETRY=1 HYPERFRAMES_SKIP_SKILLS=1 HYPERFRAMES_NO_UPDATE_CHECK=1`.
- 네트워크 우회: npm 레지스트리가 DNS로 안 잡히면 `NO_PROXY=localhost,127.0.0.1 npm_config_noproxy=localhost,127.0.0.1`로 프록시를 거치게 한다.
- 브라우저: `HYPERFRAMES_BROWSER_PATH=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
- CDN·Google Fonts는 막혀 있다. GSAP은 `npm pack gsap@3.15.0`로 받아 `assets/gsap.min.js`에 둔다. 폰트는 `@fontsource*` npm 패키지(OFL)에서 woff2를 `assets/fonts/`로 복사한다. 한글은 IBM Plex Sans KR, 낙관용 세리프는 로컬 `Noto Serif CJK KR`.
- 쓰지 않는 명령: `publish`, `cloud`, `feedback`, `skills`, `upgrade`, `auth`, `open`.
- 렌더 시간: 20초 30fps에 약 3분(단일 워커, 스크린샷 모드).

## 3. 프로젝트 구조 (luft-seoul 방식)
```
ads/video/<slug>/            9:16 프로젝트 (index.html = 생성물)
  src/template.html          원본. 두 화면비 공통, {{토큰}}으로 W/H/코어 위치 치환
  src/sound.py               사운드 디자인 합성 → assets/audio/<slug>-mix.wav
  build.py                   index.html(9:16) + ../<slug>-16x9/index.html 생성
  assets/                    gsap, fonts, img, audio
  out/                       최종 mp4(20MB 이하만 커밋)와 포스터 png
ads/video/<slug>-16x9/       16:9 프로젝트 (assets는 ../<slug>/assets 심볼릭 링크)
```
- **1080×1080 코어**: 모든 요소를 가운데 정사각 코어 안에 배치하면 9:16과 16:9 둘 다 1px = 1px로 맞는다. 9:16은 코어 top=240이어서 모든 글자가 168–1330px 안에 들어간다. 16:9는 left=420이고, 남는 좌우 공간은 카드·지도·라벨에 쓴다.
- 화면비별 보정은 `build.py`의 `LAND_CSS`와 토큰(링 배율, 카드 위치 등)으로만 한다.
- 고칠 때는 template를 고친 뒤 `python3 build.py && python3 src/sound.py`, 그다음 check, snapshot, render 순서로 진행한다.

## 5. 색·타입
- 본편: 다크 웜. 바닥 `#120E0B`, 중심 `#2A1C12`, 앰버 글로우 `#FFB066`, 빛 `rgba(255,150,70)`, 비네트 .5, 그레인 .06(overlay). 지도 장면만 차가운 보조색(슬레이트 #3E4856 계열, 시안 선 rgba(170,220,245))을 써서 앰버 경로가 뜨게 한다.
- 엔드: 브랜드 단색(LUFT `#F1C7A6`) + 블랙 `#141210`. 강조색 1개(LUFT 낙관 레드 `#C4361F`).
- 사업별 바닥색과 엔드색은 각 저장소 DESIGN/PRODUCT를 따른다. 다크+글로우 본편이 기본이고, 피치 단색 룩은 스틸 비교에서 진다(회의 기록).
- 타입: 디스플레이 Archivo 900 / stretch 62–66%, 본문 Plex Sans KR 500/700, 라벨 Plex Mono 500 대문자 자간 .08–.14em.
- 크기: 카피 120–132px, 장면 제목 64px, 캡션 40px, 라벨 22px 이상(폰 UI 내부는 예외).

## 6. 모션 규칙
- 도착은 `expo.out`/`power4.out`, 카메라는 `power2.inOut`, 퇴장·줌스루는 `power3.in`. 같은 이징을 모든 곳에 쓰지 않는다.
- 퇴장은 입장보다 40–50% 짧게. 겹침은 이전 동작이 30–50% 진행됐을 때 시작한다.
- 스태거: 글자 0.06–0.08s, 단어 0.08–0.1s, 리스트 0.04–0.07s.
- 타이틀은 착지 후 멈춘다(숨쉬기·부유 루프 금지). 움직임은 카메라·배경·다음 요소가 맡는다.
- 루트에 `data-motion-blur="on"`(셔터 200)을 켠다. SVG 필터가 걸린 요소(낙관 잉크 필터)가 있는 장면은 `data-motion-blur="off"`로 끈다(안 끄면 낙관이 사라졌다).
- `letterSpacing`·`width`·`top` 트윈은 lint 오류(프레임마다 픽셀 스냅)다. 자간 애니메이션은 `scaleX`로 흉내 낸다.
- 한글 캡션이 줄바꿈될 수 있으면 `word-break:keep-all`(안 하면 '디자인을 고 / 르고'처럼 글자 중간에서 끊긴다).
- canvas와 3D 카드는 `hf-seek`의 `renderAt(t)` 순수 함수로 그린다. 시드 PRNG(mulberry32)를 쓰고, 같은 속성을 GSAP과 동시에 건드리지 않는다.
- 전환은 영상당 3–5종을 쓰고 화면 속 원인이 있어야 한다. 예: 푸시스루(로고 확대+블러), 컨테이너 모핑(타일→상세), 이어받기(케이스가 폰에서 떠오름), 수축(낙관→지도 출발점), 아이리스 플러드(밑줄→엔드).

## 7. 사운드
- `src/sound.py`(numpy/scipy) 합성만 쓴다. 패드(장면 따라 화성 전환), 100BPM 소프트 펄스, 셰이커, 입자 쉬머, 휘시(3종 이상 변주), UI 틱, 결정적 순간 효과음 1회(LUFT 낙관 = 나무 '톡' + 종이 + 낮은 서브, 붐 금지), 엔드 히트, 짧은 플레이트 리버브.
- 큐 타이밍은 화면 동작 +1프레임(33ms). 마스터 목표는 -16~-14 LUFS(v2: -15.0), 피크 -1 dBFS 이하. `python3 src/sound.py <목표 RMS dB>`로 조정. ffmpeg `ebur128`로 잰다.
- 측정만 하고 귀로 못 들었으면 보고에 그렇게 적는다.

## 8. 품질 회의 (필수)
1. `check --json` 오류를 0으로 만든다. 경고는 이유를 적고 둔다. 렌더한 뒤 2fps 시트를 만든다(`ffmpeg -vf fps=2,scale=216:-1,tile=10x4`).
2. 아트디렉터·퍼포먼스 마케터·브랜드 매니저 3명이 레퍼런스 시트와 우리 시트를 나란히 보고 10점 만점 채점 + 고칠 점을 낸다. 가능하면 별도 에이전트로 독립 채점한다.
3. 평균 8.5 미만이면 고쳐서 다시(최대 3라운드). 회의록은 luft 저장소 `ops/ads/video/YYYY-MM-DD-meeting.md`에 남긴다.
4. 체크리스트:
   - 0프레임 훅
   - 5초 안에 USP
   - 무음으로도 이해됨
   - 9:16 글자 168–1330px 안
   - 엔드 마지막 줄 2초 이상
   - 금지어·가격·로고 없음
   - 이어받기 지점 전후 프레임에서 튐 없음
- 산출물: `out/<slug>-9x16.mp4`, `out/<slug>-16x9.mp4`, 포스터 png(결정적 순간 프레임).

## 9. 브랜드 시그니처(낙관) 규칙 — LUFT
- **크기**: 낙관은 실제 인쇄 위치·크기 그대로. 케이스 폭의 **12–15%**(현재 14%, 520px 케이스에서 73px), 케이스 **오른쪽 위 'SEOUL COLLECTION' 아래**(print/case-*.png의 '서울' 자리). 화면에서 크게 보여 주고 싶으면 낙관을 키우지 말고 **카메라가 다가간다**(매크로 푸시).
- **모양**: `#B8322A` 바탕, 바깥 빨강 4.5px + 크림(`#F6EFE3`) 안쪽 선 2px, 크림 글자(Plex Sans KR 700, 2자 세로). smartstore/detail.html의 `.seal` 스펙과 같다. SVG 필터로 가장자리를 2px 안쪽에서 흔들고, 잉크 빈 점은 드문드문(임계값 0.75 이상)만. 빈 점이 고르게 많으면 화강암처럼 보여 싸구려가 된다. `mix-blend-mode:multiply`로 종이 위 잉크처럼.
- **찍는 동작**: 1.55배 → 1배 `power2.in` 0.3초, 그림자가 오프셋에서 모이며 사라짐, 닿는 순간 0.975배 눌림 + 붉은 번짐(반경 1.7배, 0.6초) + 화면 3px 흔들림 1회. 화면 전체 빨간 플래시·셰이크·파편·충격 링 금지.
- 고해상도 케이스는 PNG 확대 금지. `print/case-*.png`(1500×3090)를 배경으로 쓰는 CSS 케이스(`.hdcase`: 520×1045, 라운드 66px, 카메라 섬 DOM)로 그린다. 낙관 자리를 지운 원본은 `assets/img/hd/ilwol-print.jpg`.

## 10. 반려에서 배운 것 (v1 → v2, 2026-11-02)
- 시그니처를 '크게 = 강하게'로 만들면 촌스럽다. 실제 제품 비율을 지키고 카메라로 강조한다.
- 입자 로고는 직선 스트로크를 쓰면 긁힌 자국처럼 보인다. 부드러운 점 스프라이트 + 6단 잔상 꼬리 + 나선형 수렴 + 해 SVG 획 위 목표점(획 폭 안 지터)으로 모으고, 모일 때 블룸 1회.
- 아이소 지도는 같은 색 블록이면 '어두운 덩어리'가 된다. 윗면/좌면/우면 명도를 1.05/0.62/0.38로 나누고, 옆면에 아래로 어두워지는 AO 그라디언트, 앞 윗모서리 림 라이트, 거리 안개, 차가운 가로등 선을 넣는다. 경로는 직각 지그재그 금지.
- 폰 UI는 작으면 글자가 안 읽히고 아래가 빈다. 9:16에서 폰 높이 ≥ 1250px, 그 아래는 바닥 그림자·반사로 채운다.
- 카피 장면에 흐린 제품을 깔면 지저분하다. 깨끗한 바닥 + 큰 글자 + 마스크.
- 엔드카드에서 제품이 워드마크 글자 일부를 가리면 실수처럼 보인다. 겹치지 않게 배치한다.
- 자체 채점은 후하다. 레퍼런스 프레임과 우리 프레임을 같은 크기로 나란히 놓고, "레퍼런스라면 이 프레임을 썼을까"로 장면마다 판정한다.
