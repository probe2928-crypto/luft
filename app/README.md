# LUFT 앱 (iOS · 안드로이드)

Capacitor 8 앱. 사이트(`../index.html`, `catalog.js`, `config.js`, `img/`)를 앱 화면으로 넣고, 앱 전용 기능을 `shell/`에서 얹는다.

- **앱 전용 기능**
  - 아래 탭(홈 · 샵 · 장바구니 · 고객센터)
  - 상품 공유(시스템 공유 창), 담기 진동
  - 안드로이드 뒤로가기, 외부 링크는 앱 안 브라우저로 열림
  - 오프라인 안내
- **새 상품**: 앱을 켤 때 사이트 `catalog.js`를 JSON으로 읽어 저장해 두었다가 씀(코드 실행 없음). 앱에 없는 새 상품 사진은 사이트 주소에서 불러옴. 앱 업데이트 없이 상품 추가가 반영됨
- **결제**
  - 사이트 `config.js`에 토스 키가 채워지면, 앱도 다음 실행부터 실결제 모드
  - 실결제 모드에서는 결제만 앱 안 브라우저의 사이트 결제 화면으로 넘김(`?cart=`). 카드사 앱 전환·인증이 웹뷰보다 안정적
- **실물 상품 판매라 Apple·Google 인앱결제 대상이 아님**(App Review 3.1.3(e), Google Play 결제 정책 예외). 수수료 없음
- **앱에서 빠지는 것**: 자매 사이트 배너(`network.js`, 코인·거래소 링크), 인쇄 원본(`print/`), 제작처 자료(`oem/`)

## 빌드
- **빌드 위치**: `probe2928-crypto/chainbrief` → Actions → **스토어 앱 (LUFT · QURATOR)**
- **서명 키**: 체인브리프 앱과 같은 Secrets를 씀(애플 4개, 안드로이드 2개)
- **안드로이드**
  - 테스트 APK: chainbrief Releases `luft-android-latest`
  - Play용 AAB: 안드로이드 서명 키가 있을 때 같이 만들어짐
- **iOS**: Secrets가 있으면 TestFlight 업로드, 없으면 시뮬레이터 빌드 확인만
- **번들 ID**: `kr.luft.store`
- **로컬 확인**: `node build-www.mjs` 후 `www/`를 아무 정적 서버로 열기
- **스토어 이미지**: `store/`
  - iPhone 6.9" 1320×2868 ×5, Play 1080×1920 ×5, 피처 그래픽, 아이콘
  - luft 저장소 Actions **스토어 이미지 (앱)**가 다시 찍음
