# 샘플 주간 준비물 (2026-11-02 주)

이번 주 케이스·방향제 샘플이 오면 이 문서 순서대로 본다: **① 검수 → ② 촬영 10컷 → ③ 사진 교체**.
방향제는 안전확인 신고번호가 나오기 전까지 판매·가격 공개 금지. 사진도 '출시 예정'으로만 쓴다.

---

## ① 도착 검수 체크리스트

받은 날 바로, 낮에 창가(자연광)에서 본다. 문제가 있으면 그 자리에서 사진 1장 + 한 줄 메모.

### 폰케이스 (서울 컬렉션)

| # | 항목 | 합격 기준 | 확인 방법 |
|---|---|---|---|
| 1 | 인쇄 해상도 | 낙관 글자·'SEOUL COLLECTION' 작은 글씨가 번지지 않고 읽힘. 계단(픽셀) 없음 | 휴대폰 카메라 2배 줌으로 글씨 확대 |
| 2 | 색 | 화면 시안(사이트 상품 사진)과 나란히 놓고 봤을 때 바탕색 차이가 '한 톤' 이내. 빨간 낙관이 주황/분홍으로 뜨지 않음 | 사이트 상품 페이지를 띄운 노트북 옆에 놓고 비교 |
| 3 | 인쇄 위치 | 낙관·로고가 테두리에서 잘리지 않음, 좌우 대칭이 맞음 | 자로 좌우 여백 비교 (1mm 이내) |
| 4 | 테두리·마감 | 측면 버(날카로운 돌기) 없음, 인쇄 들뜸·긁힘 없음, 무광 질감 균일 | 손톱으로 모서리 한 바퀴 |
| 5 | 버튼부 | 전원·볼륨 버튼이 눌림. 카메라 컨트롤(17·18 기종) 구멍 위치가 맞음 | 실제 폰 끼우고 버튼 10번씩 |
| 6 | 카메라 구멍 | 렌즈·플래시가 가려지지 않음, 테두리가 렌즈보다 살짝 높음 | 플래시 켜고 사진 1장 → 플레어 없나 |
| 7 | 장착감 | 끼우고 뺄 때 과하게 빡빡하거나 헐겁지 않음, 들뜸 없음 | 3번 끼웠다 빼기 |
| 8 | 맥세이프 | **사이트에 아직 표기 안 함.** 자석 내장 샘플이면 맥세이프 충전기·그립톡이 붙는지만 기록 | 붙음/안 붙음/약함 중 하나로 기록 → 표기는 세준 결정 후 |
| 9 | 낙관 이름 | 주문한 이름(예: 세준)이 정확, 4자는 오른쪽 줄부터 읽힘 | 주문서와 대조 |
| 10 | 포장 | 케이스 긁힘 방지 비닐·박스 상태, 기종 표기 스티커 | 사진 1장 |

## ② 실물 촬영 10컷 (세준 스마트폰)

공통 규칙
- **시간:** 맑은 날 오전 10시~오후 2시. 직사광선 말고 창가 밝은 그늘.
- **배경:** A = 피치/베이지 단색(문구점 4절 머메이드지 '살구색' 또는 '아이보리' 2장), B = 리넨/면 식탁보, C = 실제 차 안.
- **조명:** 창을 왼쪽에 두고, 오른쪽에 흰 A4/폼보드로 그림자를 살짝 밝힌다. 실내 형광등·노란 조명은 끈다.
- **카메라:** 기본 카메라 1배(광각 0.5배 금지), 격자 켜기, 렌즈 닦기, HDR 자동, 인물 모드 끄기. 정사각형이 아니라 **기본 비율(3:4)로 찍는다** — 자르기는 자동으로 한다.
- **파일명:** 아래 '파일명'대로 바꿔서 `ops/incoming/`에 올리거나 카톡으로 보내면 된다.

|---|---|---|---|---|
| 1 | `S01_case_front.jpg` | 케이스 1개 뒷면 정면 | A | 폰을 끼우고 벽에 기대 세움. 화면 중앙, 위아래 여백 넉넉히. 수평 맞추기 |

## ③ 촬영본 → 자동 교체 경로

촬영본을 `ops/incoming/`에 파일명 그대로 넣고 아래 한 줄을 돌리면 크기·비율을 맞춰 교체한다.
(케이스는 사진에 찍힌 디자인 이름을 두 번째 인자로 준다: ilwol, moonjar, celadon, najeon, peony, bojagi, dancheong)

```
python3 ops/swap_photos.py moonjar        # 케이스 컷 S01~S06 → moonjar 경로로
python3 ops/swap_photos.py --scent moonjar # 방향제 컷 S07, S09 → 해당 향 경로로
```

| 촬영 파일 | 교체되는 파일 | 크기 | 쓰이는 곳 |
|---|---|---|---|
| S01_case_front | `img/v2/<id>-front.jpg` | 1000×1000 | 상세 갤러리 2번, 스마트스토어 추가 이미지 |
| S02_case_angle | `img/v2/<id>-main.jpg` | 1000×1000 | 스마트스토어 대표, 상세 갤러리 1번 |

- 사이트 목록 사진(`img/case-<id>.jpg`, 흰 배경 컷아웃)은 실사로 바꾸지 않는다. 배경 제거가 깔끔해야 해서 3D 렌더를 유지한다.
- 교체 후엔 `smartstore/detail.html`을 다시 찍어 `detail-860.png`를 갱신한다(스크립트 안내 참고).
- 실사가 3D 렌더보다 색이 다르면 **실사 기준으로 사이트 색(stage)을 맞추지 말고** 먼저 세준에게 보여 준다.
